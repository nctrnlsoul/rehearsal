How a verdict is decided

  1. BUG only when one event id was fulfilled twice.
  2. OK only when the event was fulfilled once and a redelivery reached the store and was ignored.
  3. Anything else, including a redelivery PayPal never sent, is INCONCLUSIVE, never OK.
One class per request on the hosted demo. These two runs took about 70 seconds and 2 minutes, mostly waiting on PayPal's redelivery; longer when PayPal's event list lags.
